智慧农业监测系统

该项目为第十七届服务外包创新创业大赛A类赛事比赛项目

项目描述：基于OpenHarmony LiteOS与海思Hi3863开发智慧农业环境监测控制系统，搭建微缩农业模型，配套上位机控制APP，实现温湿度、光照、CO₂多环境参数远程监测，支持水泵、水阀、LED补光灯智能管控，自动化调控种植环境，提升农户种植管理效率，所有业务本地+云端协同运行。

技术栈：OpenHarmony LiteOS、C语言、多传感器采集、FreeRTOS任务调度、MQTT

主要负责部分与成果：

·负责智能网关底层硬件适配与驱动开发，基于OpenHarmony LiteOS封装传感器采集、定时上报、设备控制多任务；运用信号量、任务优先级调度等RTOS内核机制，解决多任务资源抢占问题，稳定承载设备接入、指令转发、联动控制业务。

·完成CO₂、土壤温湿度、光照传感器硬件对接与采集逻辑开发；设计标准化上下行数据交互帧格式，通过MQTT协议将环境数据、设备状态上传华为云IoT，对外提供标准化控制接口，支撑APP实现数据可视化、历史存储、阈值预警、远程监测。

·独立开发农业智能控制逻辑：编写土壤湿度联动自动灌溉算法、光照分级调光逻辑；搭建通用设备接入接口，拓展告警外设验证系统扩展能力；接收云端下发指令驱动水泵、水阀、LED 执行对应动作，并实时回传设备运行状态。

智能家居安防系统：

该项目参加了嵌入式软件设计大赛

项目描述：基于 STM32MP257 (A35+M33) 异构多核芯片开发本地边缘家庭安全管家。A 核运行 Linux 承载语音、Qt 界面与 NPU 视觉推理；M33 核处理实时外设控制，借助 RPMSG 完成异核交互，实现离线语音控制、人脸识别门禁、摔倒识别、消防报警全套本地业务。 

技术栈：RPMSG异核通信、外设驱动、sherpa-onnx、SenseVoice、ALSA、姿态检测、QT 

主要负责部分与成果： 
⚫在 Cortex M33 完成舵机、步进电机、CO、火焰传感器驱动与板级调试；使用 ADC 硬件过采样抑制采样噪声；基于 RIF 硬件隔离与 
ResourceManager 库管理外设资源，规避 A/M 双核并发访问寄存器冲突。 
⚫ A 核侧基于 sherpa onnx 搭建离线语音方案，依托 ALSA 完成音频链路管理，集成离线语音识别与本地 TTS，通过语音缓存优化播报
时延，实现无网环境下语音指令解析与播报。 
⚫基于 RPMSG 构建 A M 核双向通信，区分控制、告警报文；采用非阻塞读写、业务互斥机制，解决多业务算力争抢、报文乱序、音频混
音问题；统筹软硬件联调，打通整套端侧业务链路。
