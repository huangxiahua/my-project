项目描述：基于OpenHarmony LiteOS与海思Hi3863开发智慧农业环境监测控制系统，搭建微缩农业模型，配套上位机控制APP，实现温湿度、光照、CO₂多环境参数远程监测，支持水泵、水阀、LED补光灯智能管控，自动化调控种植环境，提升农户种植管理效率，所有业务本地+云端协同运行。
技术栈：OpenHarmony LiteOS、C语言、多传感器采集、FreeRTOS任务调度、MQTT
主要负责部分与成果：
·负责智能网关底层硬件适配与驱动开发，基于OpenHarmony LiteOS封装传感器采集、定时上报、设备控制多任务；运用信号量、任务优先级调度等RTOS内核机制，解决多任务资源抢占问题，稳定承载设备接入、指令转发、联动控制业务。
·完成CO₂、土壤温湿度、光照传感器硬件对接与采集逻辑开发；设计标准化上下行数据交互帧格式，通过MQTT协议将环境数据、设备状态上传华为云IoT，对外提供标准化控制接口，支撑APP实现数据可视化、历史存储、阈值预警、远程监测。
·独立开发农业智能控制逻辑：编写土壤湿度联动自动灌溉算法、光照分级调光逻辑；搭建通用设备接入接口，拓展告警外设验证系统扩展能力；接收云端下发指令驱动水泵、水阀、LED 执行对应动作，并实时回传设备运行状态。
